# alan-wechat-miniprogram-workflow

A practical workflow for building and shipping native WeChat Mini Programs with a real backend and local Docker development.

The skill guides requirement discovery, prototype and UI review, native WXML/WXSS implementation, local verification, and preview or experience-version delivery. It supports greenfield projects, existing projects, and focused fixes while respecting the requested delivery boundary.

## Use in Codex

Install the skill under `~/.agents/skills/` or a project's `.agents/skills/` directory, then invoke it with:

> Use $alan-wechat-miniprogram-workflow to help me develop a WeChat Mini Program. Start by organizing the requirements and generating the PRD and prototype. This round is local development only; do not upload.

See [`SKILL.md`](SKILL.md) for the workflow and [`references/`](references/) for checklists and templates.
